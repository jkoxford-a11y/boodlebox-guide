Student AI Toolkit

A self-guided starting point for using BoodleBox in the AI Integration Pilot.

Good AI use is active, not passive. Give the system the context it needs, choose how you want it to interact with you, compare models, and keep checking whether its answers deserve your trust.

You do not need to complete everything at once. Start with the checklist, then return when you need it.

Steps 1, 3, and 4 you work through once. Step 2 is the exception: creating your personal context file and your class bots is one-time setup, but the Course Notes Ledger you start there is a document you keep adding to all semester — that part is never quite “done.”

If this toolkit was assigned in one of your courses: download your AI Toolkit Check-In (Word doc) and keep it open as you work. You’ll see a few CHECK-IN prompts along the way telling you what to record. Short answers are expected.

Start here

  1. Learn the four things to know about AI →

    Context, accuracy, sycophancy, and model differences.

  2. Set up BoodleBox for your classes →

    Your personal AI context file, a course-notes ledger, and one tutored bot per class.

  3. Try four experiments →

    See sycophancy, model differences, verification, and your own learning happen for yourself.

  4. Use AI responsibly →

    Learning versus offloading, verification, privacy, academic integrity, model choice, and environmental concerns.

One habit to start now: if you do not know how to do something in BoodleBox, ask the bot. If the question is about learning course material, first ask whether some productive struggle would help you learn it better.
