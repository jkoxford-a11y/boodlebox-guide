BoodleBox Technical Reference

How Knowledge Bank, Bot Builder, model switching, folders, and prompt modes actually work — for when you need the mechanics, not just the getting-started version.

This is optional reference material, not required reading. Use it when a course asks you to upload knowledge, build a bot, change AI models, organize chats, or change a prompt mode and you want the exact steps. Current as of August 2026 — exact menu names may shift as the platform updates.

Knowledge Bank

The Knowledge Bank is your reusable file library. Upload a file once, then attach it to chats or custom bots when you need it.

Add a file

  1. Open Knowledge Bank from the left navigation.
  2. Select Upload Files.
  3. Drag in a file or choose one from your computer.
  4. Wait for BoodleBox to finish analyzing it.

Use Add Folder to organize files and Find Knowledge to search for them.

Attach a file to a chat

A file sitting in your Knowledge Bank is not automatically being used by the AI. It must be attached.

  1. Open your chat.
  2. Select Attach Knowledge — the paperclip near the prompt box.
  3. Choose Upload File for a new file, or From Knowledge for one already in your Knowledge Bank.
  4. Select the file.

Files uploaded directly through a chat are also saved to your Knowledge Bank for later use.

Star frequently used files

You can star a Knowledge Bank file to have it automatically attached to new chats. Useful for something you expect to use repeatedly, like a course reference or your personal AI context file.

Build a Custom Bot

A custom bot is a reusable AI assistant with its own instructions, model, and optional knowledge files.

  1. Open Bot Builder from the left sidebar.
  2. Select Build Bot.
  3. Give your bot a name.
  4. Build it using either Vibe Build (describe what you want in normal language) or Configure (directly control its settings).
  5. Test the bot.
  6. Select Publish.

What matters in Configure

  • Powered By — which AI model runs the bot.
  • Bot Instructions — what the bot should do and how it should behave.
  • Knowledge — files the bot should consistently use.
  • Bot Communications — its greeting.

Important: the greeting and profile description do not control the bot's behavior. Put behavioral instructions in Bot Instructions.

Add knowledge to a bot

  1. Open the bot in Bot Builder → Configure.
  2. Find Knowledge.
  3. Upload a file or select one from your Knowledge Bank.
  4. Select Publish Changes.

Keep the distinction clear: Knowledge Bank is your reusable file library; Bot Knowledge is files attached specifically to one bot.

Change AI Models

You can change models without starting a new conversation. The next model continues in the existing chat.

Switch models

  1. Find the current model name at the bottom-left of the chat input.
  2. Select it to open the model picker.
  3. Choose another model.
  4. Your next message goes to that model.

Find all available models

The first models shown are not the complete list.

  1. Open the model picker.
  2. Select AI Models on the left.
  3. Choose a provider such as ChatGPT, Claude, or Gemini.
  4. Expand the provider to see its available models.
  5. Select the exact model you want.

You can also search for models, or use @ when working with multiple AIs in one conversation.

Chat Folders

Folders are for organizing chats.

  1. Find My Folders in the sidebar.
  2. Select Add Folder.
  3. Name the folder.
  4. Create chats inside it or move existing chats into it.

Folders do not grant chat access. Putting a chat in a shared folder does not automatically let an instructor or classmate read it. Chat permissions are controlled for each individual chat — a folder link may let someone see that a chat exists without letting them read it.

If someone specifically needs to read one of your chats:

  1. Open the chat.
  2. Select the person-plus Share icon.
  3. Add the person or change General access as instructed.
  4. Copy the chat link.

If your course uses a formal BoodleBox Assignment, follow that assignment workflow instead of treating a folder as a submission system.

Prompt Modes

Select Set prompt mode near the bottom-right of the prompt box to turn modes on or off. Modes can be combined.

Memory Mode

Allows the AI to use information from your previous chats. Turn it on when you're continuing an ongoing project and earlier conversations provide useful context. Turn it off when you want a fresh conversation without earlier work influencing the response.

Coach Mode

Adds short AI-literacy tips to the AI's responses.

Message Mode

Posts what you type as a human message rather than sending it to the AI. Useful in shared chats.

Knowledge to Context Mode

Loads attached documents into the AI's context in full from the start. You usually do not need this — BoodleBox normally decides when a full document needs to be loaded automatically. Use it when you specifically want the entire attached document considered from the beginning.

Three Things That Are Easy to Confuse

FeatureWhat it provides
Knowledge BankFiles you save and deliberately attach
Bot KnowledgeFiles associated with a particular custom bot
Memory ModeInformation retrieved from your previous conversations

If an assignment tells you to attach a particular file, don't assume Memory Mode or merely having the file in your Knowledge Bank is a substitute.

If Something Is Not Working

The AI seems unaware of my file

Check that the file is actually attached to the chat or bot, not merely stored in the Knowledge Bank.

I cannot find a model

Open the model picker → AI Models → choose the provider and expand its complete model list.

Someone cannot read my chat

Check the chat's Share / General access settings. Moving it into a folder does not change its permissions.
